# 规划与实际交付对账（2026-11-05）

依据本仓库实现、O1–O8 / W1–W6 任务、隔离工作区实测记录和 Weavelo 的设备验收记录对账。这里区分“有基础代码”“独立实测”“部署验收”，不把跨编译、接口可调用或方案文档记作功能完成。

## 当前优先交付：手机自己连接无线 ADB

0.12.7 只能通过外部已授权 ADB 激活 shell。0.12.8 新增应用内配对通知、AndroidKeyStore 身份、本机 mDNS 发现、本机 TLS ADB 和 helper 自动激活。远程通道仍使用原 Octendra 服务，配对码只从手机界面进入，不进入 MCP 参数。

源码与单元测试已完成；正式签名、两部真实手机配对和排除 USB 激活后的恢复验证需分别记录，不能由编译成功推定。首次系统无线调试授权不可省略；系统关闭无线调试、关闭 Wi-Fi 或撤销配对时，应用需准确显示原因，不能承诺绕过系统重新开启。

## Weavelo：独立对话负责推进

以 `remote_play/docs/testing/2026-11-05-DEVICE-ACCEPTANCE.md` 为证据。管理主界面、单流远控窗口、统一操作入口和菜单快捷操作已进入实机交付，不应继续笼统列为“尚未开发”。129 桌面版和 81 Android 版的设备图标、窗口来源等验收由该对话继续；不要在它操作手机时重启相关会话。

仍未闭环的是 AI 隔离来源和共享输入接管的 W1–W3 联合验收、Windows/Linux 原生 GPU Computer Use 导出与语义树、全设备音频/相机/通知/多窗口/旋转/输入法的长时矩阵。已记录的具体问题包括 HO5 锁屏无法验收实际输入、Linux 全分辨率首帧编码超目标、努比亚微信输入法异常，以及 Redmi 的系统自动化输入限制。部分文件传输、应用流和音频实测已通过，不能据此声称整套跨平台 phone use 已完成。
